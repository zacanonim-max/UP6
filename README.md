## Возможности

- Вычисление количества дней между двумя датами (результат всегда неотрицательный, порядок дат не важен).
- Определение високосности года по григорианскому календарю.
- Проверка корректности даты: формат, диапазон месяца, число дней в конкретном месяце.
- Два режима ввода и вывода: интерактивно через консоль или через файлы.
- Понятные сообщения об ошибках и коды возврата для использования в скриптах.
- Не требует сторонних библиотек.

## Требования

- Python 3.6 или новее (используются f-строки и аннотации типов).
- Сторонние зависимости не нужны: используется только стандартная библиотека (`sys`, `os`, `argparse`, `datetime`).

## Использование

### Интерактивный режим

Запустите программу без параметров и введите две даты:

```bash
python date.py
```

```text
Введите первую дату (ДД.ММ.ГГГГ): 01.01.2024
Введите вторую дату (ДД.ММ.ГГГГ): 01.01.2025
```

### Режим работы с файлами

Чтение дат из файла и вывод результата в консоль:

```bash
python date.py --in input.txt
```

Чтение из файла и сохранение результата в файл:

```bash
python date.py --in input.txt --out result.txt
```

Ввод с клавиатуры и сохранение результата в файл:

```bash
python date.py --out result.txt
```

### Параметры командной строки

| Параметр | Описание |
|---|---|
| `--in FILE` | Файл с исходными датами (две строки). Если не указан, даты вводятся с клавиатуры |
| `--out FILE` | Файл для сохранения результата. Если не указан, результат выводится в консоль |
| `-h`, `--help` | Вывод справки |

## Формат входных данных

Две даты в формате `ДД.ММ.ГГГГ`, каждая на отдельной строке:

```text
01.01.2024
01.01.2025
```

Правила:

- разделитель — точка;
- пустые строки и пробелы по краям строк игнорируются;
- файл должен быть в кодировке UTF-8 (желательно без BOM);
- дата должна существовать в календаре (например, `29.02.2023` — ошибка).

## Формат результата

```text
Дата 1: 01.01.2024 (високосный год)
Дата 2: 01.01.2025 (невисокосный год)
Количество дней между датами: 366
```

В консольном режиме вывод предваряется заголовком `--- Результат ---`.

## Обработка ошибок

Сообщения об ошибках выводятся в стандартный поток ошибок (`stderr`).

### Коды возврата

| Код | Значение |
|---|---|
| `0` | Успешное выполнение |
| `1` | Ошибка данных (неверный формат, несуществующая дата, недостаточно дат) или ошибка ввода-вывода |
| `2` | Входной файл не найден |

### Примеры сообщений

| Причина | Сообщение |
|---|---|
| Неверный формат | `Ошибка: Ожидается формат ДД.ММ.ГГГГ, получено: '1-1-2024'` |
| Нецифровые символы | `Ошибка: Дата содержит нецифровые символы: 'аа.бб.вввв'` |
| Месяц вне диапазона | `Ошибка: Месяц вне диапазона 1..12: 13` |
| Несуществующий день | `Ошибка: День 29 вне диапазона для 02.2023 (в месяце 28 дней)` |
| Введена одна дата | `Ошибка: Нужно ввести две даты (каждая на отдельной строке).` |
| Файл не найден | `Ошибка: файл не найден: input.txt` |

## Как это работает

Год считается високосным, если он делится на 4, но не делится на 100, либо делится на 400:

```python
(year % 4 == 0 and year % 100 != 0) or (year % 400 == 0)
```

Например, 2000 и 2024 — високосные годы, 1900 и 2100 — невисокосные.

Основные функции:

| Функция | Назначение |
|---|---|
| `is_leap_year(year)` | Проверка года на високосность |
| `days_in_month(year, month)` | Количество дней в месяце с учётом високосного года |
| `parse_date(s)` | Разбор и проверка строки даты `ДД.ММ.ГГГГ` |
| `days_between(d1, d2)` | Количество дней между датами (по модулю) |
| `calculate(text)` | Обработка двух строк с датами и формирование результата |
| `main(argv)` | Точка входа: разбор аргументов, ввод, вывод, коды возврата |
