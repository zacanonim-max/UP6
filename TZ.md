# Техническое задание на разработку программного обеспечения

## 1. Введение и требования к программе

В рамках учебной практики по профессиональному модулю ПМ 06 «Сопровождение информационных систем» необходимо выполнить разработку и сопровождение консольной программы на языке программирования Python. 

Основная задача программы заключается в нахождении количества дней между двумя произвольными датами, вводимыми пользователем в формате ДД.ММ.ГГГГ. Программа должна корректно обрабатывать ввод данных и учитывать високосные годы при расчете разницы в днях.

В рамках учебной задачи по сопровождению ИС, помимо разработки основного функционала, необходимо выполнить следующие дополнительные работы:
- Реализовать механизмы резервного копирования и восстановления пользовательских календарей для программного обеспечения.
- Разработать и составить полную пользовательскую документацию к программе.
- Разработать набор тест-кейсов для проверки корректности работы алгоритмов расчета дат, обработки различных сценариев ввода данных и работы функций резервного копирования.

## 2. Функциональные требования

### 2.1. Основной функционал
- Программа должна принимать два значения даты от пользователя.
- Программа должна принимать данные в формате ДД.ММ.ГГГГ (например, 01.01.2020).
- Программа должна вычислять абсолютную разницу в днях между введенными датами.
- Алгоритм расчета должен учитывать особенности високосных лет (количество дней в феврале, правила определения високосного года).
- Программа должна выводить результат расчета в консоль.

### 2.2. Функционал сопровождения и обслуживания
- **Резервное копирование:** Программа должна обеспечивать возможность сохранения текущих данных календаря в файл резервного копирования.
- **Восстановление:** Программа должна иметь возможность загрузки данных из файла резервного копирования для восстановления состояния календаря.
- **Тестирование:** Необходимо подготовить описание тест-кейсов, покрывающих:
    - Корректный ввод дат (простые случаи).
    - Ввод дат, разделенных високосными годами.
    - Ввод дат, находящихся в одном и том же году.
    - Некорректный ввод формата даты (обработка исключений).
    - Проверка корректности работы механизмов бэкапа и восстановления.

## 3. Технические требования

### 3.1. Язык программирования и среда выполнения
- Язык разработки: Python 3.x.
- Интерфейс взаимодействия: Консольный (CLI).

### 3.2. Требования к документации
- Документация должна включать:
    - Инструкцию пользователя (описание интерфейса, способов ввода данных и интерпретации результатов).
    - Техническое описание алгоритмов (описание логики расчета дат и работы с файловой системой для бэкапа).

## 4. Состав deliverables
1. Исходный код программы на Python.
2. Файл пользовательской документации.
3. Реестр тест-кейсов.
4. Отчет о выполнении учебной практики.
