# Date

Консольная утилита на Python для:
1. Расчёта количества дней между двумя датами в формате `ДД.ММ.ГГГГ` с учётом високосных лет.
2. Резервного копирования и восстановления пользовательских календарей (JSON).

Поддерживает ввод/вывод как через консоль, так и через файлы.

---

## Требования

- Python 3.8+
- Только стандартная библиотека (`datetime`, `argparse`, `json`, `hashlib`, `shutil`, `pathlib`)

---

## Установка

Скопируйте файл `date_calc.py` в рабочую директорию. Никаких зависимостей устанавливать не требуется.
